# Разбор: сайт с бизнес-идеями

Статический сайт без сборки: три файла, ничего не нужно устанавливать.

- `index.html` — страница, стили и логика
- `content.js` — весь контент: темы, разборы идей, книги
- `README.md` — эта инструкция

## Как работает

Человек выбирает тему (ИИ-стартапы, маркетплейсы, онлайн-услуги, контент, образование, личные финансы) и сразу видит разборы идей по этой теме и книги. Выбор запоминается и попадает в адрес страницы (`#ai`, `#money` и т. д.), так что на конкретную тему можно дать ссылку.

Внизу блок «Проверь свою идею»: человек описывает идею, сайт собирает готовый запрос, который вставляют в Алису или Yandex GPT. Это работает без сервера и без расходов.

## Как запустить на Vercel

Аккаунты GitHub и Vercel лучше оформить на родителя или с его участием.

1. Создай репозиторий на GitHub и загрузи в него три файла.
2. Зайди в Vercel, нажми **Add New → Project** и выбери этот репозиторий.
3. Framework Preset оставь **Other**, команды сборки не нужны. Нажми **Deploy**.
4. Через минуту сайт откроется по адресу вида `название.vercel.app`.

Каждое изменение в GitHub будет само обновлять сайт.

## Важно про деньги и тариф Vercel

По правилам Vercel бесплатный тариф Hobby только для личных некоммерческих проектов, а любое коммерческое использование требует платного тарифа Pro. Пока сайт просто проект для практики и портфолио без рекламы, платных функций и продаж, Hobby подходит. Как только появятся реклама, партнёрские ссылки или платные разборы, нужно переходить на Pro или переносить сайт на другой хостинг. Актуальные условия смотри на странице Fair Use Guidelines на vercel.com.

## Как добавлять контент

Открой `content.js`, скопируй любой блок внутри `ideas`, поменяй текст и оценки. Новая тема добавляется копированием целого блока с `id`, `name`, `intro`, `ideas` и `books`. Кнопка темы на странице появится сама.

Правила качества:

- Оценки от 1 до 5 это мнение. Не пиши цифры дохода, если не можешь назвать источник.
- Книги и сервисы называй только те, в существовании которых уверен.
- Проверяй каждый разбор сам, прежде чем публиковать.

## Следующий шаг: разбор прямо на сайте

Когда будет аудитория, кнопку «Скопировать запрос» можно заменить на настоящую проверку идеи через Yandex GPT. Для этого понадобится серверная функция Vercel (папка `api/`), а ключ доступа хранится в Environment Variables, а не в коде. Оплата и аккаунт Yandex Cloud оформляются на взрослого.
